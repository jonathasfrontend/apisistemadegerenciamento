# Fixtures PDF (F3)

As amostras JPG na raiz do projeto são **faturas de imagem**, não PDFs —
`pdfjs-dist` extrai texto e não vai conseguir lê-las sem OCR (fora de escopo,
decisão: sem OCR). PDFs reais de extrato/fatura, anonimizados, ficam pendentes
e serão definidos na parada da Fase 2 (decisão D4).

Esta pasta existe só para reservar o local. Não copiar os JPGs para cá.
